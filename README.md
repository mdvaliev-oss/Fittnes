# 🏋️ Fittnes — Персональный тренер по силовым тренировкам

Профессиональное мобильное приложение для силовых тренировок в зале:
дневник тренировок, база упражнений с техникой, умные рекомендации весов,
графики прогресса и модель восстановления мышц.

Уровень продукта — Strong / Hevy / Fitbod, с более научным подходом к силе.

## 📱 Скачать APK (Android)

Готовый установочный `.apk` собирает GitHub Actions на каждый пуш в ветку.

1. Открой вкладку **[Actions → Build Android APK](https://github.com/mdvaliev-oss/Fittnes/actions/workflows/android-apk.yml)**
   (нужно быть залогиненным на GitHub).
2. Выбери верхний зелёный запуск → внизу блок **Artifacts** →
   скачай **`fittnes-release-apk`** (zip, внутри `app-release.apk`).
3. Перекинь файл на телефон и открой — Android попросит разрешить установку
   из этого источника, разреши → «Установить».

> APK подписан отладочным ключом — этого достаточно для личного теста.
> Полный гайд (в т.ч. локальная сборка и iOS) — в [`MOBILE.md`](MOBILE.md).

## Стек

| Слой | Технология |
|------|-----------|
| Framework | Flutter 3.44+ / Dart 3 |
| State / DI | Riverpod 2 (провайдеры вручную, без codegen) |
| Навигация | go_router (StatefulShellRoute) |
| Каталог упражнений | Bundled JSON (131 упражнение) → in-memory репозиторий |
| БД (local-first) | Drift / SQLite — тренировки, история, PR, вес тела |
| Графики | fl_chart (сила / тоннаж / вес тела) |
| Техника | Векторная фигура на CustomPainter (IK-риг, 31 паттерн движения) |
| Анимации | Собственные микро-анимации (PressableScale, StaggeredFadeIn, конфетти PR) |

## Что умеет (v0.4)

- **Тренировка**: подходы с весом/повторами/RPE/RIR, типы подходов, суперсеты,
  авто-таймер отдыха (длительность настраивается), подсказки «прошлый раз»,
  умные рекомендации, баннер «Новый рекорд!».
- **Единицы**: кг или фунты — переключатель в настройках и прямо в тренировке;
  всё хранится в кг, конверсия только на экране.
- **Вес тела**: ввод в кг или lb, история с дельтами, график за 90 дней,
  карточка на Главной, синхронизация с профилем.
- **Упражнения**: 131 упражнение с подробными описаниями, техникой, советами и
  ошибками; анимированный показ техники (вид сбоку/спереди, скамья, штанга,
  перекладина, подсветка работающих мышц); каталог с группами мышц, фильтрами,
  избранным, списком/сеткой.
- **Прогресс**: тоннаж, рост силы (e1RM), личные рекорды, вес тела.
- **Программы**: пресеты + конструктор своих программ.
- **Восстановление**: модель усталости мышц → тепловая карта тела.
- **Профиль и данные**: цели, 1ПМ, тема, напоминания, экспорт/импорт JSON.

Архитектура: **Clean Architecture + Feature-First** (`presentation → domain ← data`),
Repository Pattern, SOLID, MVVM через Riverpod-нотифаеры. Local-first, офлайн;
облачная синхронизация — отдельный модуль.

## Запуск

Проект собран как исходники модулей. Перед первым запуском создайте
платформенные папки и подтяните зависимости:

```bash
flutter create . --project-name fittnes --platforms=android,ios
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # ОБЯЗАТЕЛЬНО (Drift)
flutter run
```

> ⚠️ С Модуля 2B проект использует Drift. Сгенерированный
> `lib/core/database/app_database.g.dart` намеренно не в репозитории —
> без `build_runner` сборка упадёт. Запускайте кодоген после каждого
> изменения схемы БД.

Тесты и анализ:

```bash
flutter analyze
flutter test
```

## Дорожная карта (модулями)

> **Текущая поставка:** Модули 0–4B готовы. Модуль 4C (конструктор своих
> программ) и Модуль 5 (синхронизация/экспорт/уведомления/виджеты) —
> запланированы, но в эту поставку не входят.


- [x] **Модуль 0 — Фундамент**: дизайн-система, glass-тема, core-виджеты,
      навигация (bottom-nav shell), главный экран-витрина.
- [x] **Модуль 1 — База упражнений**: доменные сущности, in-memory репозиторий,
      сид-каталог (JSON), живой поиск + фасеты (мышца/оборудование/уровень),
      экран техники (зацикленная анимация) + векторная подсветка мышц (`MuscleMap`).
- [x] **Модуль 2A — Движок тренировки**: доменные модели (сессия/подход/PR),
      e1RM (Epley), контроллер активной сессии, экран логирования подходов
      (вес/повторы/RPE/RIR, типы подходов, суперсеты), авто-таймер отдыха,
      подсказки прошлой тренировки и рекомендованный вес, PR — на in-memory
      репозитории за интерфейсом `WorkoutRepository`.
- [x] **Модуль 2B — Персистентность**: Drift/SQLite (`WorkoutRepositoryDrift`)
      за тем же интерфейсом, экран истории тренировок, живые метрики на главной
      (серия, недельный тоннаж, число тренировок, лучший e1RM).
- [x] **Модуль 3 — Прогресс + Рекомендации**: движок автопрогрессии
      (`ProgressionEngine`: двойная прогрессия × RPE/RIR → поднять/снизить вес,
      добавить повтор, разгрузка, больше отдыха), рекомендация в карточке
      упражнения с кнопкой «Применить», графики силы (e1RM) и тоннажа на
      `fl_chart`, список личных рекордов.
- [x] **Модуль 4A — Программы + Профиль + Настройки**: пресеты программ
      (Full Body / Upper-Lower / PPL) с запуском дня в тренировку (веса от
      движка), профиль (замеры/цель/опыт/максимумы) с персистентностью
      (shared_preferences), реальное переключение темы (свет/тёмная/система)
      и единиц измерения.
- [x] **Модуль 4B — Recovery**: модель усталости мышц (экспоненциальное
      затухание стимула по группам за 7 дней) на heat-карте тела `MuscleBodyMap`,
      готовность тела и восстановление по группам.
- [x] **Модуль 4C — Пользовательские программы**: конструктор своих программ
      (дни, упражнения из каталога, схемы подходов), персистентность в
      SharedPreferences, запуск дня в тренировку, удаление.
- [x] **Модуль 5 — Экспорт/импорт + напоминания**: экспорт всех данных
      (профиль/настройки/программы/история) в JSON и импорт-восстановление,
      локальные напоминания о тренировке (`flutter_local_notifications` +
      `timezone`) с настройкой времени. Облачная синхронизация и домашние
      виджеты — платформо-зависимые, вне текущей поставки (выбран local-first).

## Данные упражнений

Каталог грузится из `assets/exercises/exercises_seed.json` в индексированный
in-memory репозиторий (справочные данные только для чтения — БД не нужна).
Схема JSON совместима с [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
(MIT, ~800 упражнений): чтобы расширить базу до 500+, достаточно
сконвертировать датасет в этот формат и заменить asset — код менять не нужно
(`ExerciseDto`/`Muscle.fromDataset` уже понимают эти поля).
